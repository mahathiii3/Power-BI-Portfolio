# ✦ PROJECT OVERVIEW

> **An interactive Power BI dashboard designed to transform large-scale sales data into meaningful business insights.**

This project focuses on analyzing sales performance, profitability, quantity, shipping costs, markets, categories, countries, and cities through an interactive **Business Intelligence dashboard**.

The dashboard demonstrates the complete analytics workflow — from **data preparation and transformation to visualization and business analysis**.

# 🗂️ DATASET

The dataset contains detailed order-level information covering customers, products, geography, sales, shipping, profit, and returns.

## 📋 Dataset Structure

| Sheet | Records | Description |
|:---|---:|:---|
| 📦 **Orders** | **51,289** | Main sales and order-level data |
| 🔄 **Returns** | **1,173** | Returned orders and market information |
| 👥 **People** | **13** | Regional people/manager information |

# 🎯 PROJECT OBJECTIVE

The primary objective of this project was to build a complete **Business Intelligence dashboard** from a large raw dataset.

### The project focuses on:

- Understanding raw business data
- Cleaning and transforming data
- Creating meaningful KPIs
- Building analytical visualizations
- Identifying business patterns
- Comparing sales and profitability
- Presenting insights through an interactive dashboard
